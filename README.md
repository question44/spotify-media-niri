# Spotify Media for Niri

Noctalia plugin repository for the Niri-adjusted Spotify Media bar widget.

- Plugin manifest and instructions: [`spotify-media-niri/`](spotify-media-niri/)
- Plugin ID: `question44/spotify-media-niri`

Add this repository as a Noctalia plugin source:

```sh
noctalia msg plugins source add spotify-media-niri git https://github.com/question44/spotify-media-niri
```
